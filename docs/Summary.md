**NodAI** is a community where people share AI models and GPU power. People can use models, run AI, and pay with the platform token. People who provide models or GPU power earn from it.

### 1. Home

* Explore AI models
* Explore GPU power
* See top creators
* Search

### 2. Models

Creators can:

* Upload a model
* Add a name and description
* Set a price
* Earn when people use it

Users can:

* Browse models
* Try models
* Use models
* See ratings and usage

### 3. GPU Market

People with unused GPUs can offer them.

Example:

> RTX 5090
> $0.30 per hour
> Available now

Users can rent that power to run AI.

### 4. Earn

Creators earn from their models.

GPU owners earn from their GPUs.

The platform takes a small fee.

### 5. Nod Token

**$NOD** is the platform's main currency.

People use NOD to:

* Use AI models
* Rent GPU power
* Buy model access
* Earn rewards

### 6. Wallet

Every user gets a simple wallet showing:

> **2,450 NOD**

They can add, spend, and withdraw their earnings.

### 7. Profiles

Each creator gets a simple profile showing:

* Models
* Earnings
* Reputation
* Usage
* Reviews

### 8. Main Goal

**Upload AI → Use AI → Share GPU → Earn NOD**

The whole platform should feel like a **simple AI marketplace**, not a complicated crypto website.
